## 1. 产品概述

项目部桩基施工进度 Web 看板，供项目经理、总工和生产经理每日晨会使用。系统以数据可视化方式呈现桩基施工全流程状态，核心解决施工进度不透明、产能分析滞后、风险发现不及时的管理痛点。

- 主要用途：桩基施工进度跟踪、每日产能分析、风险预警
- 目标用户：项目经理、总工、生产经理
- 产品价值：让管理层一眼看清桩基施工推进情况，晨会决策效率提升 80%

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 项目经理 | 账号登录 | 全局看板查看、日报分析、风险处理 |
| 总工 | 账号登录 | 技术参数查看、检测结果回填 |
| 生产经理 | 账号登录 | 进度看板、日报汇总、班组管理 |

### 2.2 功能模块

1. **进度看板页**：楼栋/轴线/区段视图切换、桩位状态热力图、桩号详情弹窗
2. **日报汇总页**：日期选择、产能统计图表、机组产量排名、异常原因分析
3. **风险提醒页**：风险列表置顶、风险分类标签、一键定位桩位

## 3. 核心流程

### 3.1 晨会使用流程

1. 生产经理打开进度看板，选择当日视图
2. 查看各楼栋/区段桩位状态分布
3. 点击红色风险区查看具体风险桩号
4. 切换至日报汇总页，查看昨日产能数据
5. 筛选低效钻机，分析异常原因
6. 晨会讨论制定当日施工计划


## 4. 用户界面设计

### 4.1 设计风格

- 主色调：工业深蓝 `#1E3A5F`，体现工程管理专业感
- 辅助色：状态五色体系 - 未开工灰 `#6B7280`、成孔中蓝 `#3B82F6`、待灌注橙 `#F59E0B`、已完成绿 `#10B981`、待检测紫 `#8B5CF6`
- 风险色：警示红 `#EF4444`
- 布局：顶部导航 + 左侧筛选 + 主内容区，三栏式专业布局
- 字体：标题使用 `Barlow Condensed` 粗体，数据展示使用 `JetBrains Mono` 等宽字体，正文使用 `Noto Sans SC`
- 图标：使用简洁线性图标，避免复杂装饰
- 动效：数据加载渐入、状态切换平滑过渡、风险警示呼吸灯效果

- 触控设备优化按钮点击区域 ≥ 44px
